# Barbershop & Salon Website Template

A responsive, configurable website template for barbershops and beauty salons, built for small businesses in the Dominican Republic.

## Features
- Two ready-made versions: barbershop and salon
- Services and prices list, gallery, hours and location
- Appointment booking that opens WhatsApp with the message ready
- Mobile-first, supports light and dark mode

## Tech stack
HTML5, CSS3, vanilla JavaScript

## Customize it
Edit the CONFIGURATION block at the top of `script.js` (phone number, business name, services, prices, hours, address).

## Run locally
Open the folder in VS Code and use the Live Server extension.
